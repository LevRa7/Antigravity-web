# 📝 Changelog — Antigravity Web

## [2.6.0] — 2026-08-13

### 🔥 Новые возможности
- **Выпадающее меню `Accounts` в Top Navbar:** Интегрировано выпадающее меню со списком подключенных аккаунтов, индикатором текущего активного аккаунта `✓`, кнопками добавления аккаунтов и открытия менеджера.
- **Интерактивные модальные прогресс-бары:** Реализованы плавные анимированные прогресс-бары для отображения этапов активации аккаунта (`15% -> 65% -> 100%`) на `/login` и в IDE.
- **Авто-реинжект и синхронизация:** Добавлена автоматическая запись активного токена в Linux SecretService Keyring, SQLite базу данных IDE `state.vscdb` и конфигурационные файлы `~/.gemini/`.

### 🐛 Исправления ошибок и оптимизации
- **Безопасный перезапуск `language_server`:** Устранена ошибка `listen tcp 127.0.0.1:9000: bind: address already in use` за счет принудительного завершения старого PID процесса перед повторным стартом службы.
- **Корректировка таймштампов в Keyring:** Исправлена ошибка `RangeError: Invalid time value` при конвертации секунда/миллисекунда для токенов Google OAuth.
- **Фильтрация шума DevTools:** В `polyfill.js` добавлен фильтр логов для `reconnectableStream` (`stream error: ConnectError: Error in input stream` и `disconnected, retrying in...`), обеспечивший 0 ошибок и 0 предупреждений в консоли браузера.
- **Валидация Sourcemap:** В Nginx добавлен заглушечный обработчик файлов `.map`, исключивший ошибки парсинга карт кода в Firefox DevTools (`JSON.parse: unexpected character`).
- **Авто-перенаправление при сбое авторизации:** Внедрен модуль `checkAuthFailure`, перенаправляющий пользователя на `/login` при появлении экранов `Authentication Required` или `Authentication failed`.
